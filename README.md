# GitLume · Git 桌面客户端

一个面向小白、简洁风格的 Windows Git 图形化客户端。不用记任何 Git 命令，选文件夹 → 填备注 → 一键提交并推送，其余全部自动完成。

> 替代手敲 `git init / add / commit / remote add / pull / push` 等一长串命令。

---

## 功能特性

- **智能初始化**：选择项目文件夹后自动判断是否初始化过，未初始化点「提交并推送」自动执行 `git init`（只需一次），首次提交自动合并云端历史
- **全局配置自动保存**：填一次用户名/邮箱自动保存，所有操作自动带上，不用再输
- **多仓库同时推送**：可添加多个远程仓库（Gitee / GitHub / GitLab / 私有仓库都行），一键同时上传到所有仓库
- **每个仓库独立账号**：不同仓库可以用不同用户名密码，登录时窗口会明确提示当前是哪个仓库；能直接连上的公开仓库不弹窗
- **密码加密存储**：记住的密码以简单加密写入本地配置文件，推送时自动解密使用
- **智能交互**：禁止弹出 VIM 编辑器；禁止 Git Credential Manager 弹出白色系统对话框；认证失败自动弹窗重试
- **自动配置恢复**：关闭软件后，下次打开自动恢复用户名、邮箱、仓库列表
- **全程日志反馈**：每一步执行的 git 命令和结果实时显示，出错有清晰中文提示

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / Windows 11 |
| Git | 已安装 [Git for Windows](https://git-scm.com/download/win)（命令行 `git --version` 可用） |
| 运行 | .NET 8 运行时（或更高，自动向上兼容）；源码构建需要 .NET 8/9 SDK 或 Visual Studio 2022（17.8+） |

## 构建与运行

### 方式一：Visual Studio 2022（推荐）

1. 安装 VS2022 并勾选「.NET 桌面开发」工作负载
2. 双击打开 `GitLume.sln`
3. 按 `F5` 直接运行

### 方式二：命令行

```bash
dotnet build GitLume/GitLume.csproj -c Debug
dotnet run --project GitLume/GitLume.csproj
```

### 方式三：一键启动脚本

双击根目录的 `启动GitLume.bat`：自动检测 Git、自动编译、启动软件。

## 小白快速上手（30 秒）

1. 顶部「全局配置」填好 **用户名** 和 **邮箱**（离开输入框自动保存，填一次即可）
2. 点「选择...」选中你的 **项目文件夹**（软件会自动判断 Git 状态）
3. 在「本次修改的备注」里写一句说明（如：更新了登录功能）
4. 点 **「提交并推送」** —— 其余全部自动完成！

> 之后的每一次更新，重复第 2、3、4 步即可。不用管初始化、不用管拉取、不用管推送命令。

## 多仓库账号与密码说明

- 每个远程仓库可以**独立记住用户名密码**：推送时若某仓库需要登录，会弹出窗口并标明「正在为哪个仓库（名称 + URL）输入凭据」
- 勾选「记住密码」后，该仓库的密码会以**加密形式**存入配置文件；下次推送到该仓库自动使用，不再弹窗
- 若某个仓库公开、无需认证，或凭据已正确保存，则**全程不会弹窗**
- 如果密码输错，认证失败后**不会保存错误密码**，避免下次卡死

### 密码加密算法（公开透明）

采用 **XOR 异或 + Base64** 混淆加密，密钥为固定字符串：

```
密钥: GitLume@2026#Enc#SimpleKey

加密（明文 → 密文）：
  1. 密钥字符串按 UTF-8 转字节数组 key
  2. 明文密码按 UTF-8 转字节数组 data
  3. 逐字节异或：data[i] = data[i] XOR key[i % key.length]
  4. Base64 编码后写入配置文件

解密（密文 → 明文）：
  1. Base64 解码得到字节数组
  2. 用同一个密钥逐字节异或还原
  3. UTF-8 解码得到明文密码
```

> 说明：这是"混淆级"加密，用于防止直接打开配置文件看到明文密码；密钥在程序内部，属于轻量方案。如需更高安全性可改用系统级加密（DPAPI），可在项目中扩展。

## 数据文件（不写系统盘）

软件运行产生的所有文件都在**软件所在目录**，不向 C 盘 / 系统盘写入任何内容：

| 文件 | 位置 | 说明 |
| --- | --- | --- |
| `config.json` | 软件目录下 | 配置：用户名、邮箱、仓库列表、加密密码 |
| `crash.log` | 软件目录下 | 仅在程序异常崩溃时生成（正常使用不会出现） |

其余操作日志只显示在软件界面（内存中），点击「清空日志」即可释放。

## 常见问题

- **编译报错 / dotnet 找不到**：请安装 .NET 8 SDK，或用 VS2022 打开 `GitLume.sln` 编译
- **推送提示"认证失败"**：在弹窗中确认当前仓库的用户名密码是否正确（Gitee 通常为用户名 + 密码或私人令牌）
- **第一次推送提示合并**：属正常现象，软件会自动处理云端已有内容与本地历史的合并
- **出现白色弹窗**：如果看到白色系统登录框，说明 Git Credential Manager 未被禁用，请确保使用最新版本（已默认禁用）
